# Marco Rocha - Milestone I E-Portfolio

Resume content is based on the supplied CV. Phone number and home address are omitted.
The Minimal theme was downloaded as a ZIP from https://github.com/pages-themes/minimal/archive/refs/heads/master.zip, extracted, and copied into this repository.
The theme license is in LICENSE; the original repository license is in REPOSITORY-LICENSE.

## Enable GitHub Pages

1. Open this repository's Settings > Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Select main and / (root), then Save.
4. Open Actions and check the pages build and deployment run for the latest main commit.
5. Confirm that build and deploy succeed, then open the URL shown in Settings > Pages.
6. Check the resume sections, LinkedIn and email links, stylesheet, placeholder logo, and mobile layout.

The site URL is https://marcorocha-nam.github.io/620-V2/.

Replace assets/img/logo.png with your headshot using the same filename.
For local preview, install Ruby and Bundler, then run `bundle install` and `bundle exec jekyll serve`.
